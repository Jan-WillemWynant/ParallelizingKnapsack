# Parallelizing Knapsack

This repository contains a branch-and-bound algorithm for the 0/1 knapsack problem. It contains an initial sequential algorithm, which explores the solution space by branching on the decision to include a particular object into the knapsack or not. The repository furthermore contains two parallel versions of this branch-and-bound approach, in which the exploration of the search tree is distributed over multiple threads. In the first parallel version (MultithreadedKnapsack.cpp), the search tree is distributed once across the threads. In the second parallel version (MultithreadedKnapsack.cpp), work is re-assigned to threads which finish early, making the distribution of the search tree across the threads dynamic. 

More detailed information can be found in the project report, which is also included in the repository. This project report also describes the experimental results from running the three versions on a few test instances. The experimental results show that the parallel versions speed up the algorithm, i.e. the parallel versions reach the exact solution faster. The test instances are also included in the repository.

The initial sequential algorithm was developed as part of the Combinatorial Optimization and Local Search Techniques course at the KU Leuven. The test instances were also provided to me by professor Erik Demeulemeester as part of the aforementioned course. The two parallel versions were developed as part of the Practical Parallel Programming course at the VUB.
